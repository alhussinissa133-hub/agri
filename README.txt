تطبيق الأندرويد فقط — محاسبة الصيدلية الزراعية
==============================================
طريقة 1: على GitHub (بدون تثبيت شيء عندك)
  - أنشئ مستودعاً (Public إذا بدك تحديث من داخل التطبيق)، ارفع محتويات هذا المجلد (مع المجلد المخفي .github).
  - Actions ← Android APK ← Run workflow ← اكتب 1.0.0.
  - بعد ~5 دقائق: حمّل AgriPharmacy.apk من Artifacts أو من Releases.
  - للتحديث لاحقاً: شغّل نفس الـ workflow برقم أعلى (1.0.1) وثبّت الـ APK فوق القديم (البيانات تبقى).
طريقة 2: على ويندوز: شغّل build-android.bat (يحتاج Node.js + JDK 17 + Android Studio).
مهم: لا تحذف/تغيّر build\debug.keystore (مفتاح التوقيع الثابت)، وإلا يرفض الهاتف التحديث فوق القديم.
بعد التثبيت: الدخول الأول المدير / 1234، وربط الأجهزة من الإعدادات بالـ QR.
